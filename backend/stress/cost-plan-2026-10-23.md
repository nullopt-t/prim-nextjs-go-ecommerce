## 2. What each tier means

- **Budget / self-managed:** Hetzner, OVH, or similar. You run Postgres streaming replication, PgBouncer, Redis Sentinel, backups, and monitoring yourself. Cheapest, but requires ops time and discipline.
- **Balanced / managed DB:** App nodes on a cheap VPS provider, but Postgres and Redis are managed (DigitalOcean, Aiven, Neon, Supabase, Upstash). Higher bill, much lower operational risk — this is usually the best "stable + affordable" trade-off.
- **Hyperscaler:** AWS/GCP/Azure equivalents, Multi-AZ, managed services, on-demand. Easiest to scale and audit, roughly 2–4× the balanced cost, with egress as a hidden multiplier.

All tiers assume:
- 2+ API nodes behind a load balancer (no single point of failure).
- Database in the same region, with automated backups/PITR and at least one replica.
- Redis with a replica.
- Object storage + CDN for product images.
- Monitoring and alerting.

| Component | Budget (dedicated) | Balanced (managed) | Hyperscaler |

| Read replicas | 3–4 × 16–32 vCPU | 3–4 managed replicas | 3–4 × db.r7g.2xlarge |

| Redis | 16–32 GB cluster | Managed cluster | ElastiCache cluster |
| Kafka | 3–5 brokers | Managed | MSK 3–5 |
| Load balancer | 2 × 4 vCPU / 8 GB | Managed LB | ALB/NLB |
| Object storage | 4–5 TB | 4–5 TB | S3 4–5 TB |
| Backups / monitoring / CDN | dedicated + Cloudflare | managed | CloudWatch/CloudFront |
| **Estimated total** | **$1,500–3,000** | **$5,000–8,000** | **$12,000–18,000** |

At this scale:
- **The database cluster dominates the bill**, not the API nodes.
- A single primary is a risk; plan read replicas, catalog caching, time-partitioned orders/events, and async processing.
- Egress on AWS/GCP can add **$500–2,000/month** on top unless you front media with Cloudflare/Bunny and keep traffic in-region.
- Budget **0.5–1 SRE** if self-managed; that often costs more than the infrastructure.

## 6. Hidden and easily-forgotten costs

| Item | Typical cost | Notes |
|---|---|---|
| Bandwidth / egress | $0–1,500/mo | Included generously on Hetzner; expensive on AWS/GCP. Use a CDN for images. |

| **SMS OTP** | **$0.04–0.10 per message** | 60k logins × $0.06 = **$3,600 per full wave**. Prefer email OTP or WhatsApp; this can dwarf infra. |
| Backups & PITR | 10–25% of DB cost | Non-negotiable for "stable". |
| Monitoring / error tracking | $20–200/mo | Grafana Cloud, Sentry, UptimeRobot. |
| CDN / WAF | $0–200/mo | Cloudflare Free/Pro often enough. |
| Staging environment | 20–40% of production | Necessary to test deploys and load. |
| Engineering / on-call | $2,000–10,000/mo | Depends on whether you self-manage. |
| Payment processing | ~2.9% + $0.30/transaction | Not infrastructure, but real. |

## 7. How to stay affordable without sacrificing stability

1. **Split the tiers:** cheap, reliable VPS/ dedicated compute for stateless API nodes; managed Postgres for the data you cannot lose.
2. **Commit where steady:** 1-year reserved/committed use for the DB and baseline API capacity; autoscale only the burst.
3. **Keep the database close:** same region/AZ group; avoid cross-region chatter.
4. **Cache aggressively:** catalog/product reads are the bulk of the measured traffic. A Redis hit rate of 70–80% cuts DB size and cost more than any instance tweak.
5. **Use object storage + CDN** for images; never serve media from the API.
6. **Set budgets and alerts** at 50/80/100% of expected spend; egress and managed DB storage are the usual surprises.
7. **Right-size after re-benchmarking** with per-user carts and a tuned pool — the current 1,250 rps ceiling is pessimistic.
8. **Start smaller than the table** if launch traffic is uncertain: 2 API nodes + a managed DB with a replica can be upgraded in minutes.

## 8. Recommended starting point (most likely: 60k DAU)

A stable, reasonably priced stack:

- **API:** 3 × 8 vCPU / 16 GB (Hetzner CPX41 or DigitalOcean equivalent), behind a managed load balancer.
- **Postgres:** managed 16 vCPU / 64 GB with one read replica, PITR, and automated failover.
- **PgBouncer:** managed or 2 small instances.
- **Redis:** managed 8 GB with replica.
- **Kafka:** defer until async notifications/analytics justify it; a database outbox + worker is cheaper at this stage.
- **Storage/CDN:** S3-compatible object storage + Cloudflare.
- **Monitoring:** Prometheus/Grafana + Sentry + uptime checks.

**Estimated: $1,000–1,300/month**, or **$500–700/month** if you self-manage Postgres and Redis on Hetzner/OVH. Add 20% headroom for backups, bandwidth, and growth.
